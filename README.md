Golden Hour Cover Studio — an offline web app that turns a photo and a caption into GTA-style multi-panel cover art: hero + stacked panels (Poster), 2×2 Grid, or hero + 3 rows (Strip), in four sunset/neon colour grades, exported as PNG in 1080×1080, 1080×1350 or 1920×1080. Every panel can be panned by dragging, zoomed with the wheel or sliders, and filled with the user's own photo or a sample; the kicker, title and tagline are editable. Sun, palms, stars, the VOL. 01 stamp, halftone and vignette are all drawn in canvas code. Original photos made for this entry plus the kit's free samples; fonts Anton & Pacifico ship under the SIL Open Font License. No Rockstar Games logo, artwork, character or game font is used.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Build the submission output with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
